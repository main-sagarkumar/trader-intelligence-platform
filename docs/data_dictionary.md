# Trader Intelligence Data Dictionary

## trader_metrics

| Column | Description |
|----------|------------|
| trader_id | Unique trader identifier |
| persona | Simulated trader archetype |
| total_trades | Total trades executed |
| total_pnl | Total profit and loss |
| avg_pnl | Average profit/loss per trade |
| win_rate | Winning trades percentage |
| avg_holding_minutes | Average holding duration |
| avg_leverage | Average leverage used |
| avg_risk_pct | Average risk per trade |
| roi_pct | Return on investment |
| cluster | Trader behavior segment |
